# Сторонние компоненты

Весь код шаблона распространяется по 0BSD (`LICENSE`). Стороннего кода в репозитории нет:
ни библиотек, ни кода клиента игры, ни чужих модов.

## Форматы CPython 2.7

`tools/py27c.py` — собственная реализация компилятора. Чтобы получить настоящий байткод
Python 2.7, он использует интерфейсные факты CPython 2.7: номера опкодов, `cmp_op`, флаги
`CO_*`, коды типов `marshal` и магическое число `.pyc`. Исходный код CPython в шаблон не
скопирован. CPython — © Python Software Foundation, лицензия PSF-2.0.

## Внешние инструменты (не входят в шаблон)

Шаблон ничего из этого не содержит и не распространяет. Каждый инструмент пользователь ставит
сам, а скрипты шаблона запускают его отдельным процессом. Поэтому лицензии этих инструментов
на лицензию шаблона не влияют.

| Инструмент | Лицензия | Зачем | Обязателен |
|---|---|---|---|
| Python 3.10+ | PSF-2.0 | запуск `build.py` и `tools/*.py` | да |
| Python 2.7 | PSF-2.0 | запасной компилятор точки входа (`build.py --compiler py27`) | нет |
| uncompyle6 | GPL-3.0 | декомпиляция `scripts.pkg` вашего клиента (`tools/extract_client_source.py`), проверка `py27c.py --self-test` | нет |
| xdis | GPL-2.0 | дизассемблер, зависимость uncompyle6, проверка `py27c.py --check-opmap` | нет |
| spark-parser | MIT (файл `LICENSE` пакета) | зависимость uncompyle6 | нет |
| click | BSD-3-Clause | зависимость uncompyle6 и xdis | нет |
| six | MIT | зависимость xdis | нет |

Версии, с которыми проверялся шаблон, закреплены в `tools/requirements-decompile.txt`.

**Не встраивать.** uncompyle6 и xdis — под GPL. Окружение `.tools/venv_uncompyle` ставится
пользователем локально и в `.gitignore` исключено. Не коммитьте его в репозиторий шаблона
или своего мода и не кладите в один архив или установщик с ними: такая поставка стала бы
производным GPL-комплектом.

## Игра

Шаблон работает с файлами игры «Мир танков» (Lesta Games), установленной у пользователя, но
ничего из них не содержит и не распространяет. Права на игру, её код и данные принадлежат
правообладателю.
